Entorno de Pruebas: Subida de Archivos y Gestión de Almacenamiento

Borrador Temporal de Pruebas
1. Autenticación y Cuota de Almacenamiento
Inicia sesión o pega tu token JWT para operar sobre /api/storage.
Sin sesión activa 0 B / 5 GB (0%)
2. Subir Archivo (Multer)
Envía multipart/form-data a POST /api/storage/upload en la carpeta actual.
3. Nueva Carpeta
Crea una carpeta en el nivel actual mediante POST /api/storage/folders.
4. Explorador de Mis Archivos
Navega por carpetas, busca por nombre, consulta recientes, descarga, renombra o elimina elementos.
