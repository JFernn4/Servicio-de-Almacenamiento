VinCloud — Verificación de Correo y Recuperación de Contraseña

Actualiza usuario.correo_verificado y usuario.contrasena_hash en PostgreSQL

Tokens de Propósito de Un Solo Uso + Invalidación de Sesiones

1. Verificar Cuenta con Token en PostgreSQL (POST /api/auth/verify)

Introduce el token de verificación (si acabas de registrar un usuario en la pestaña 2 o reenviar correo, se autocompleta automáticamente).

2. Generar / Reenviar Token de Verificación (POST /api/auth/resend-verification)

Ingresa un correo registrado no verificado para emitir un nuevo token y autocompletarlo arriba.

3. Recuperación de Contraseña de Un Solo Uso (/forgot-password y /reset-password)

Comprueba que al restablecer la contraseña en PostgreSQL: 1) el token de recuperación queda invalidado inmediatamente si intentas usarlo una segunda vez, y 2) todas las sesiones abiertas previamente se cierran automáticamente.
